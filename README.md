# korokoro-block

タブレットを傾けてボールを転がす、ブロックの世界のブラウザゲーム「ころころ ブロックワールド」。

- HTML + JavaScript のみ（ビルド不要）
- タブレットの傾きセンサー（DeviceMotion / DeviceOrientation）で操作
- GitHub Pages で公開: https://ryokkon624.github.io/korokoro-block/

## ページ

| ファイル           | 内容                                 |
| ------------------ | ------------------------------------ |
| `index.html`       | ゲーム本編                           |
| `sensor-test.html` | 傾きセンサーの動作確認用テストページ |

## ファイル構成

| ファイル        | 内容                                                     |
| --------------- | -------------------------------------------------------- |
| `js/main.js`    | 画面の切り替え（タイトル → ステージえらび → プレイ → クリア） |
| `js/game.js`    | ゲーム本体（ボールの動き・当たり判定・描画）             |
| `js/stages.js`  | ステージのデータ                                         |
| `js/art.js`     | ブロックとアイテムのドット絵                             |
| `js/sensor.js`  | 傾きセンサー・全画面・画面固定・スリープ防止             |
| `js/sound.js`   | 効果音・バイブ                                           |
| `js/save.js`    | セーブ（localStorage）                                   |
| `css/style.css` | 画面のスタイル                                           |

## ステージの作り方

`js/stages.js` に 16 × 10 マスの文字で書く。外周はかべにすること。

| 文字 | 意味         | 文字 | 意味           |
| ---- | ------------ | ---- | -------------- |
| `#`  | いしのかべ   | `S`  | スタート       |
| `=`  | いたのかべ   | `G`  | ゴール         |
| `T`  | はっぱのかべ | `o`  | わなのあな     |
| `.`  | くさ         | `w`  | 木（アイテム） |
| `~`  | こおり       | `r`  | 石（アイテム） |
|      |              | `f`  | 花（アイテム） |
|      |              | `d`  | ほうせき（アイテム） |

## 傾きセンサーについて

- 傾きセンサーは HTTPS（または localhost）でしか動かないため、実機確認は GitHub Pages 上で行う
- 遊ぶときはタブレットの画面の自動回転をオフにする（ボタンを押すと全画面＋その時点の横向きで固定する）

## ローカルでの確認

```sh
python -m http.server 8765
# http://localhost:8765/ を開く
```

PC ではマウスでドラッグした方向にボールが転がる。
